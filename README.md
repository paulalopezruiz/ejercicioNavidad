# Menú navideño 🎄

Ejercicio para practicar con Bootstrap y aprender a usar GitHub Pages.

## Tareas a realizar

Utilizando Bootstrap crea una página que contenga una invitación a una comida/cena de Navidad.

Incluye el menú y un formulario para confirmar la asistencia.

Publica la página en GitHub Pages de modo que sea accesible desde cualquier lugar.

Incluye el enlace a la página al final de este README.
